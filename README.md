# Shot Tracker

Upload a slow-mo clip of a shooter and get every shot's trajectory drawn on one image and one video.
Runs entirely in the browser (a single `index.html`, no server, no uploads).

## Put it online with GitHub Pages (free)
1. Sign in at github.com and click **New repository**. Name it e.g. `shot-tracker`, set it to **Public**, tick **Add a README**, click **Create**.
2. In the repo click **Add file > Upload files**, drag in `index.html` from this folder, then **Commit changes**.
3. Go to **Settings > Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
4. Wait ~1 minute. Your site is at `https://YOUR-USERNAME.github.io/shot-tracker/`.

## Tips for good results
- Camera held still (tripod), side-on to the shot path.
- Record in the phone's Slo-mo mode and upload the original file.
- Pick the ball colour (yellow is the tuned one; red and blue are experimental).
